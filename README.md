# Exusiai

Exusiai is a Slay the Spire 2 character mod built around fast attacks, Rapid Fire copies, Gunspark token generation, Overclock turns, custom relics, bilingual localization, and Exusiai-themed character visuals.

## Requirements

- Slay the Spire 2
- BaseLib 3.3.2
- Godot/MegaDot 4.5.1 Mono
- .NET SDK compatible with the project

## Installation

Public release page:

```text
https://www.nexusmods.com/slaythespire2/mods/1078
```

Delete any old `Exusiai` mod folder before installing a new release.

For players, install the release files into:

```text
Slay the Spire 2/mods/Exusiai
```

The folder should contain exactly these mod files:

```text
Exusiai.dll
Exusiai.json
Exusiai.pck
```

BaseLib must also be installed and enabled. Do not rename the `Exusiai` folder or the three release files.

## Troubleshooting

If cards show placeholder text such as `If you can read this, there is a bug`, the mod code or packed assets did not load correctly. Check:

- The folder is exactly `Slay the Spire 2/mods/Exusiai`.
- The folder contains `Exusiai.dll`, `Exusiai.json`, and `Exusiai.pck`.
- BaseLib is installed and enabled.
- Old files from previous versions were removed before reinstalling.
- The newest game log has no `Exusiai` or `BaseLib` load errors.

The public beta branch may change STS2 APIs before the stable branch. If this happens only on beta, include the game branch, BaseLib version, and the newest log when reporting it.

## Build

```powershell
dotnet build D:\work_console\MyFirstMod\MyFirstMod.csproj
```

The build copies `Exusiai.dll`, `Exusiai.json`, and the current `Exusiai.pck` into:

```text
D:\SteamLibrary\steamapps\common\Slay the Spire 2\mods\Exusiai
```

## Export PCK

```powershell
& 'D:\work_console\workspaceforexusuai\megadot-4.5.1-m.9-windows-x86_64-llvm-editor-csharp\MegaDot_v4.5.1-stable_mono_win64_console.exe' --headless --path 'D:\work_console\MyFirstMod' --export-pack BasicExport 'D:\work_console\MyFirstMod\Exusiai.pck'
```

Then copy it into the game mod directory:

```powershell
Copy-Item -LiteralPath 'D:\work_console\MyFirstMod\Exusiai.pck' -Destination 'D:\SteamLibrary\steamapps\common\Slay the Spire 2\mods\Exusiai\Exusiai.pck' -Force
```

The exporter currently prints known Godot noise about `sts2` assembly lookup. Treat the export as successful when `Exusiai.pck` is written.

## Release

Use the one-command release script after validating the mod in game:

```powershell
.\tools\Release-Exusiai.ps1 -Yes -Description 'Release notes here.'
```

By default, the script packages the currently deployed files from:

```text
D:\SteamLibrary\steamapps\common\Slay the Spire 2\mods\Exusiai
```

This is intentional: after an in-game test pass, the release zip should contain the same `Exusiai.dll`, `Exusiai.pck`, and `Exusiai.json` bytes that the game just loaded.

To verify the package without uploading to Nexus:

```powershell
.\tools\Release-Exusiai.ps1 -DryRun
```

Dry runs write to `dist\dry-run\` so they do not overwrite the real release zip. Use `-Source Build` only when intentionally publishing freshly rebuilt output instead of the deployed, play-tested files:

```powershell
.\tools\Release-Exusiai.ps1 -Source Build -Yes -Description 'Release notes here.'
```

## Core Features

- Custom playable character: Exusiai.
- Rapid Fire keyword: creates a copy of the played card; the copy gains Ethereal and Exhaust and cannot trigger Rapid Fire again.
- Gunspark token engine: zero-cost attacks generated by multiple cards and relics.
- Power package: Overclock, Sweep Mode, Spark Circuit, Fire Control, Angel's Blessing, and Chain Reaction.
- Custom relics: Sniper's Chipset, Spark Capacitor, Tactical Magazine, and Reticle Calibrator.
- Chinese and English localization.
- Custom card art, relic icons, power icons, character select visuals, battle visuals, merchant visuals, and rest-site visuals.

## Important Notes

- The user-facing mod name, manifest, DLL, PCK, and deployment directory are `Exusiai`.
- Internal resource paths and localization IDs still use `myfirstmod` / `MYFIRSTMOD-*` for compatibility with existing references and saves.
- `CardTemplate` is the internal class name for Crossfire. It is kept for compatibility.
- Rest-site visuals are created by `ExusiaiRestSiteCreatePatch` at runtime to avoid the old scene-root type issue that caused rest-site freezes.
